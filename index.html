這是什麼

AzureWorks 是一座等角控制平面城市。部署推車載著一筆 ARM 要求 （即將成為的 VM，或滑桿指定的 Azure Container Apps／App Service 修訂）。推車 沿工廠線穿過 Entra 大門、角色櫃檮、原則大廳、標籤與鎖定場、 VNet 場、存取岔路、倉庫、運算棚、瞭望塔與保險庫。 原則可把它導入拒絕岔線。網路存取是岔路：公用 IP、Bastion 或 Private Endpoint。

推車上的儀表是每月費率表總額。車斗裡的木箱是 備援複本。兩者都直接讀自 js/model.js。

保真帳本

已計算：RBAC 繼承 + 動作聯集；原則拒絕；NSG 先符合者勝； 備援複本數；費率表每月成本；備份儲存估算 （0.05 × diskGb × (retentionDays / 30)）。

已縮尺：角色動作只有少數動詞；一個 VNet、一個子網路、一張 NIC； 一套原則；幾個 VM SKU。

已假設：離開 Entra 大門後權杖有效（沒有真正的 OIDC）；一個區域； 一個訂用帳戶；730 小時月；每日備份 RPO。App Service 方案倍率與 Azure Container Apps 執行體數由大小滑桿對應，讓那支滑桿永遠推動一個數字。

已偽造：Entra 權杖密碼學；真正的 ARM/Bicep 編譯；即時 Azure 零售價；Site Recovery 容錯移轉；Advisor 建議；SSPR／授權／ 外部使用者；AzCopy；完整負載平衡器資料路徑。

僅指示：建築尺寸、區名、旁白裡任何不在面板上的數字。

本頁不會寫錯的事實

  • 租用戶擁有 Microsoft Entra ID。訂用帳戶活在租用戶底下。管理群組巢狀於訂用帳戶之上。
  • 名稱是 Microsoft Entra ID，不是 Azure AD。
  • Azure Policy 是治理，不是存取控制。鎖定與 RBAC 正交。
  • 參與者不能指派角色。擁有者與使用者存取系統管理員可以。
  • 可用性區域不是可用性設定組。
  • ACR 是登錄，不是執行階段。Azure Container Apps 是應用程式平台。
  • Private Endpoint 不是服務端點。
  • 價格是一小張費率表，不是即時 Azure 價格。

刻意不在範圍內（有點名，不成站）：SSPR、外部使用者、授權、物件 複寫、主機加密、UDR 表、Application Gateway 對 LB、KQL 查詢。

步調

推車第一次抵達一站時，會停夠久讓你讀完該站說明—— 介於 9 到 26 秒——面板文字下方的進度條顯示還剩多少停留。 每一站都講過之後，城市以可觀看的速度跑。Space 可無限停在任一站，S 一次走一站，速度滑桿縮放一切，包含閱讀停留。 重設（⟲）重播慢速導覽；執行保留你已經讀過的。

操作

  • Space 播放／暫停 · S 前進一站 · R 重設並重播導覽 · F 跟隨鏡頭 · L 標籤
  • 拖曳平移，滾輪縮放，點任一站看說明。
  • 視圖一開始貼近推車並跟著走。⤢ 按鈕，或雙擊地圖，拉遠看整座城。
